# MEET KI DUKAAN Franchise Website

A complete, professional, high-converting franchise website for MEET KI DUKAAN built with Next.js, Tailwind CSS, and Framer Motion.

## 🚀 Features

- **Modern Design**: Premium, responsive UI with glassmorphism effects and smooth animations
- **High Performance**: Optimized for speed with Next.js 16 and image optimization
- **SEO Optimized**: Complete SEO setup with meta tags, sitemap, and structured data
- **Mobile First**: Fully responsive design with mobile navigation drawer
- **Interactive Components**: Testimonial sliders, FAQ accordions, and animated sections
- **Professional Forms**: Contact and franchise application forms with validation
- **Conversion Focused**: Strategically placed CTAs and trust indicators

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Images**: Next.js Image optimization
- **Fonts**: Inter (Google Fonts)

## 🚀 Getting Started

### Prerequisites

- Node.js 20.9.0 or higher
- npm or yarn

### Installation

1. Clone the repository:

```bash
git clone <repository-url>
cd ecomdukan
```

2. Install dependencies:

```bash
npm install
```

3. Run the development server:

```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🔧 Configuration

### Environment Variables

Create a `.env.local` file for environment-specific configurations:

```env
NEXT_PUBLIC_SITE_URL=https://franchise.ecomseekho.com
NEXT_PUBLIC_CONTACT_EMAIL=franchise@ecomseekho.com
NEXT_PUBLIC_CONTACT_PHONE=+91 98765 43210
```

### Image Optimization

Images are configured to load from `customer-assets.emergentagent.com` domain. Update `next.config.mjs` to add additional image domains if needed.
